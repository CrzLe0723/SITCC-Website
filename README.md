# 🐯 SITCC Website

The official website for the **St. Ignatius Tigers Coding Club (SITCC)**.

SITCC is a student-led coding club where students learn programming, make games, participate in challenges, and share their creations with other students.




## 🌐 About the Website

The SITCC website is designed to be the central hub for the club.

It includes:

- 🎮 Club games
- 📰 Club news and updates
- 📚 Coding tutorials
- 🏆 Achievements and competitions
- 👥 Community information
- 📅 Meeting schedule
- 🤝 How to join
- 📖 Club information
- 💻 Coding resources
- 🏅 Code Clash information
- 👑 Club leadership
- 📜 Website version history

SITCC uses MakeCode Arcade to teach students programming and game development.

- Club competition games
- Multiplayer games
- Monthly challenge games
- Example games
## 🏆 Club Features

Some of the planned and existing features include:

Code Clash

A school-wide coding tournament where students compete in games.

Monthly Challenges

Members create games based on a specific challenge or theme.

Game Gallery

A collection of games created by SITCC members.

Coding Tutorials

Beginner-friendly tutorials covering programming concepts such as:

- Variables
- If statements
- Loops
- Enums
- Debugging
- JavaScript
- Game development
- Community

A place to highlight members, projects, achievements, and club news.

## 🐛 Bug Reports

Found something broken?

Report it to the SITCC leadership or use the website's contact form.

When reporting a bug, try to include:

- What you were doing
- What you expected to happen
- What actually happened
- Which page or feature was affected
