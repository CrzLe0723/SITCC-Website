# Contributing to the SITCC Website

Thank you for your interest in contributing to the **St. Ignatius Tigers Coding Club (SITCC) Website**!

The website is a student-led project, and contributions are welcome from SITCC members who want to help improve the website.

## 📋 Before Contributing

Before making a contribution:

- Check the existing [Issues](https://github.com/CrzLe0723/SITCC-Website/issues) to see if the idea or problem is already being discussed.
- For larger changes, open an issue first so the change can be discussed.
- Make sure your contribution follows the [SITCC Code of Conduct](CODE_OF_CONDUCT.md).
- Do not include passwords, API keys, tokens, private information, or other secrets in your contribution.
- Only contribute content or assets that you have permission to use.

## 💡 Suggestions and Issues

If you find a bug, have an idea, or notice something that should be improved, you can open an issue.

When creating an issue, try to include:

- A clear title
- A description of the problem or idea
- Steps to reproduce the problem, if applicable
- Screenshots or examples when helpful

Please search existing issues before creating a duplicate.

## 🔧 Making Changes

### 1. Fork the Repository

If you are contributing from outside the main repository, create a fork of the repository.

### 2. Create a Branch

Create a branch for your change rather than working directly on `main`.
