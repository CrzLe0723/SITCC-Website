# Contributing to the SITCC Website

Thank you for your interest in contributing to the **St. Ignatius Tigers Coding Club (SITCC) Website**!

The website is a student-led project, and contributions are welcome from SITCC members who want to help improve the website.

## 📋 Before Contributing

Before making a contribution:

- Check the existing [Issues](https://github.com/CrzLe0723/SITCC-Website/issues) to see if the idea or problem is already being discussed.
- For larger changes, open an issue first so the change can be discussed.
- Make sure your contribution follows the [SITCC Code of Conduct](CODE_OF_CONDUCT.md).
- Do not include passwords, API keys, tokens, private information, or other secrets in your contribution.
- Only contribute content or assets that you have permission to use.

## 💡 Suggestions and Issues

If you find a bug, have an idea, or notice something that should be improved, you can open an issue.

When creating an issue, try to include:

- A clear title
- A description of the problem or idea
- Steps to reproduce the problem, if applicable
- Screenshots or examples when helpful

Please search existing issues before creating a duplicate.

## 🔧 Making Changes

### 1. Fork the Repository

If you are contributing from outside the main repository, create a fork of the repository.

### 2. Create a Branch

Create a branch for your change rather than working directly on `main`.

Use a descriptive branch name, such as:

```text
feature/add-tutorial
fix/navigation-menu
content/update-news
```
### 3. Make Your Changes

Make your changes while keeping the existing structure and style of the website.

For example:

* Keep HTML organized and readable.
* Keep CSS consistent with the existing styles.
* Use clear JavaScript names and comments when needed.
* Keep files in their appropriate directories.
* Avoid unnecessary changes to unrelated files.
### 4. Test Your Changes

Before submitting your contribution:

Open the website and test the changes.
Check the affected pages.
Test navigation and links.
Check the browser console for errors when appropriate.
Make sure your changes work on different screen sizes when relevant.
### 5. Commit Your Changes

Use a clear commit message describing what you changed.

Examples:

Add coding tutorial page
Fix navigation menu
Update club news
Improve mobile layout
6. Open a Pull Request

Push your branch to GitHub and open a Pull Request against the main branch.

Your Pull Request should explain:

What you changed
Why you changed it
How you tested it
Any additional information reviewers should know
## 🔍 Pull Request Review

Pull Requests may be reviewed before being merged.

A contribution may be asked to be changed if it:

Introduces bugs
Does not follow the project's structure or style
Contains unauthorized or copyrighted material
Introduces security or privacy concerns
Conflicts with the goals of the SITCC Website
Needs additional testing or documentation

Not every Pull Request will necessarily be accepted.

## 🔐 Security Issues

Please do not report security vulnerabilities publicly in a GitHub Issue if the issue could expose a secret, private information, or a serious security vulnerability.

See [SECURITY](SECURITY.md) for information about reporting security issues.

## 📜 Content and Assets

Only contribute content, images, icons, music, code, or other materials that you have permission to use.

If an asset comes from another creator or source, make sure its license permits its use and provide attribution when required.

Do not upload:

* Passwords or API keys
* Personal information
* Private communications
* Unlicensed copyrighted material
* Other sensitive information
## 📝 Documentation

If your change affects how the website works, consider updating the relevant documentation.

Keep documentation understandable for students with different levels of programming experience.

## 🐯 SITCC Values

Contributions should help make the SITCC Website a welcoming, educational, and useful resource for the coding club.

Be respectful, collaborate constructively, and remember that the goal is to help students learn and create.

Thank you for contributing to SITCC! 🐯
