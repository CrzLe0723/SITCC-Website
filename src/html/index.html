Mini Tutorial: If Statements

Posted on January 14, 2026

What is an If Statement?

An if statement lets your program make a choice. It runs code only if a condition is true. You can also use else to run code when the condition is false.

Syntax:

▶ Show Code 

              if (info.score() > 10) {
                game.splash("You won!");
              }

Quick Check: When does this code run?

Example: Check if a player has enough points to win.


You can also use else if to enhance your condition further!

Syntax:

▶ Show Code 

                if (health >= 100) {
                  console.log("Full health!");
                } else if (health <= 20) {
                  console.log("Almost dead!");
                } else if (health <= 50) {
                  console.log("Not doing so well!");
                } else {
                  console.log("Player is dead!");
                }

Mini Tutorial: Enums

Posted on February 2, 2026

Language: JavaScript

An enum (short for enumeration) is a way to give names to a fixed set of values. Instead of remembering numbers like 0, 1, 2, you use meaningful names.

Why Enums Are Useful (Game Example)

Imagine a game where a player can be in different states: Idle, Running, Jumping, Game Over. Without enums, you might do this

▶ Show Code 

                let playerState = 1; // what does 1 mean?

These are called Magic Numbers and we don't like them!


Using an Enum

You can make an enum by typing the key word enum and then the name of the enum

▶ Show Code 

                  enum PlayerState {
                    IDLE = 0, // shows what is the value of the index as enums are also numbers 
                    RUNNING =  1,
                    JUMPING =  2,
                    GAME_OVER =  3
                  }

                  //Another Example:
                  enum GameState {
                    Main_Menu,
                    Playing,
                    Paused,
                    GAME_OVER
                  }

Now use it like this

▶ Show Code 
let playerState = PlayerState.IDLE;

Using Enums with If Statements

You can even use enums in if statements!

▶ Show Code 

                if (playerState == PlayerState.JUMPING) {
                  console.log("Player is jumping!");
                }

Changing States

▶ Show Code 
playerState = PlayerState.RUNNING;

Later changed to:

▶ Show Code 
playerState = PlayerState.GAME_OVER;

Mini Tutorial: Debugging Errors

Posted on January 14, 2026

What is Debugging?

Debugging is the process of finding and fixing errors (bugs) in your code. It helps your program work correctly and prevents unexpected behavior.

Steps to Debug:

  • Read Error Messages: Look at what the console or program tells you. It often tells you the line number and type of error.
  • Check Syntax: Missing semicolons, brackets, or parentheses are common errors.
  • Use Console Logs: Add console.log() to check variable values or the flow of your program.
  • Break Down Code: Test smaller pieces of your code separately to isolate the problem.
  • Ask Questions: Sometimes explaining the problem aloud helps you see mistakes.

Example:

let score = 10;

            // Suppose this is giving an unexpected result
            if (score = 5) {  // Error: used = instead of ==
                console.log("Score is 5!");
            }

            // Fix:
            if (score == 5) {  // Correct: use == for comparison
                console.log("Score is 5!");
            }

            // Add console logs to debug
            console.log("Current score:" + score);
Cruz Le

Test Small, Debug Big

Posted on January 14, 2026

Tip: When writing code, test small parts at a time. If something breaks, it’s easier to find the problem and fix it. This keeps your code from becoming a big confusing mess!

Cruz Le

How To Share Your Game:

You can share your game with other people by opening up your game on Makecode Arcade and click the three connected dots near the top right corner of the web page. Then pressing Share Game and copying the link (optionally, you can share your game with embed code, on Facebook, on Twitter, on Google Classroom, and much more!).


Hosting a Game/Joning a Game

Hosting a game:To host a game (if you're the hoster), click the Host multiplayer game button underneath the gameboy/your game. Then clicking the Host button and Share and Host. Now, tell your friends to enter the link near the code (Example: D45B4E). Now wait for your friends to join and start playing (NOTE: gameplay might be different on other devices). Optionally, you can also host pre-made games by going to the link near the code: Join a game here!


How To Join a Game

To join a game, go the specified link the hoster is telling you, or if on mobile, scan the QR code. Once you have gotten to the link, enter the code near the QR code and press Enter. Now wait for the host to start the game and have some fun!
